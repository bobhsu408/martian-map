# AI 使用紀錄（AI / "SI" Usage Log）

NASA Space Apps 規定提交時必須完整揭露 AI（官方稱 Super Intelligence, SI）的使用方式。
本檔持續記錄每一個用到 AI 的步驟。提交時，團隊會根據本檔**自己寫**一段誠實的英文說明。

## 分工原則（2026-11-14 起，依台灣評審公告調整）
| 團隊自己做（原創核心） | 可以交給 AI（工具性質） |
|---|---|
| 科學目標、地點、為什麼選 boxwork | 環境建置、專案骨架、樣板程式 |
| 成本函數的權重和門檻：自己決定、調整並說明理由 | 測試的寫法（測試情境由團隊決定） |
| 情境設計：基地、落石位置、O2 參數 | 除錯、解釋錯誤訊息 |
| 路線比較和 replan 的判斷邏輯 | 英文文法潤飾（只修文法，不改內容和語氣） |
| Demo 故事、介面要呈現什麼 | README、格式整理 |
| 英文提交內容的初稿 | |

- AI 只對「團隊自己做」的部分**解釋原理、給提示、審查**，不直接寫出完整實作。
- Git 慣例：AI 產生的 commit 都帶有 `Co-Authored-By: Claude` 標記；團隊自己的修改由自己 commit，訊息寫清楚做了什麼。
